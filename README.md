## Descripción del proyecto

Este proyecto tiene como propósito analizar la evolución de las emisiones de dióxido de carbono (CO₂) en Colombia mediante el uso de herramientas de ciencia de datos y programación en Python.

Se realizará la descarga, exploración y limpieza de datos, su representación mediante gráficos y la aplicación de un modelo de regresión lineal para estudiar su comportamiento a través del tiempo.
